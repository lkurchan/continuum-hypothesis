# Tarea 0 — Base del repositorio

## Objetivo y alcance

Preparar el monorepo de Continuum para que los módulos A, B, C y D puedan trabajar con las interfaces de las secciones 7 y 8 de `PRD.md`. El alcance es el de `docs/prompts/tarea-0.md`: estructura, dependencias, firmas, stubs y configuración. No se implementa lógica de negocio, ni se despliegan contratos o transacciones en mainnet.

## Entregables

- `contracts/`: Foundry, Solidity 0.8.24, OpenZeppelin, remappings y `ContinuumStreams.sol` con struct, eventos y funciones que revierten con `NotImplemented()`.
- `web/`: Next.js App Router, TypeScript (target ES2020 para los bigint internos del gateway), Tailwind, ESLint, viem, Supabase y Vitest; tipos y gateway según el PRD; vesting y ABI pendientes; constantes de Arbitrum/ARGt; rutas HTTP con respuesta 501; páginas y carpetas mínimas para pagador y trabajador. Node.js 24 se fija en `.nvmrc` y `engines`.
- `web/.env.example`: configuración sin secretos; modo mock por defecto; claves demo `PLATFORM`, `WORKER1` y `WORKER2`; sin clave de Anthropic en esta etapa.
- `supabase/`: migración de las cuatro tablas del PRD y seed repetible de tres usuarios con direcciones placeholder. Las claves privadas nunca se guardan en la base.
- Raíz: ignore de artefactos y secretos, README mínimo e instrucciones equivalentes en `CLAUDE.md` y `AGENTS.md`, con comandos operativos.
- Servicios externos: crear Supabase y Vercel únicamente si hay una conexión autenticada disponible; en caso contrario documentar la configuración pendiente (Vercel con raíz `web`).

## Contratos de integración

Se mantienen los tipos `DemoUser`, `StreamView`, `Activity`, `Amount` y la interfaz `StreamGateway` del PRD. `vestedAt` devuelve `Amount` y por ahora arroja `TODO B1`. `getGateway()` selecciona `mock` o `real` con `CHAIN_MODE`, y arroja respectivamente `TODO B2` o `TODO B5`. Ningún stub realiza escrituras ni simula transacciones exitosas.

## Criterios de aceptación

1. `forge build` compila con Solidity 0.8.24; `forge test` puede ejecutarse sin los ejemplos Counter.
2. `npm run build`, `npm run lint`, `npm run typecheck` y `npm test` pasan en `web/`.
3. Las siete combinaciones de método/ruta de la API, excluyendo el agente, responden HTTP 501 y `{ "error": "not implemented" }`.
4. `/`, `/payer` y `/worker` se renderizan sin depender de credenciales o fuentes remotas.
5. No se versionan claves privadas, `.env` reales, dependencias generadas o artefactos de compilación.
6. Los cambios se registran en commits pequeños con Conventional Commits y la identidad Git ya configurada. La excepción explícita de la tarea 0 permite trabajar y publicar directamente en `main`.

## Fuera de alcance

Implementación del contrato, fórmula de vesting, gateways mock/real, handlers funcionales, diseño final, agente, wallets y fondeo. Esas tareas conservan los responsables definidos en el PRD.
