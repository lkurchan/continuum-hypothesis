# Continuum

Pagos por segundo para freelancers y trabajadores de plataformas, en pesos onchain con ARGt sobre Arbitrum One.

Ver [PRD.md](PRD.md) para alcance, arquitectura e interfaces, y [docs/SETUP.md](docs/SETUP.md) para instalar la base y preparar Supabase y Vercel.

Estado: backend demo funcional con `CHAIN_MODE=mock`; ver [docs/BACKEND.md](docs/BACKEND.md). Contrato y UIs en construcción. El modo real requiere el despliegue del contrato y la configuración de servicios. ARGt es un medio de pago, sin rendimiento.
